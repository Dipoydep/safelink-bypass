# Safelink Bypass

Bypass safelink (sfl.gl / safelinku / khaddavi) via Termux + Python.
Jalan di HP Android — pake IP rumahan, lolos Cloudflare.

## Fitur

- **Bypass otomatis** — fetch safelink, dapet URL target
- **HTTP server lokal** — buka di browser HP, tinggal paste link
- **Web UI** — form input + result box (SVG icons)
- **Cookie session** — handle `/api/session` + `/api/go` khaddavi
- **Gratis** — gak butuh VPS, jalan di HP kamu
